# 📊 Sentiment Analysis Dashboard

A lightweight, interactive web application that performs real-time sentiment analysis on text input. Built with Python, Streamlit, and TextBlob.

## Features
* **Real-time Processing:** Enter any text and instantly receive sentiment feedback.
* **Polarity Scoring:** Measures how positive or negative the text is (from -1 to 1).
* **Subjectivity Scoring:** Evaluates whether the text is factual or opinion-based (from 0 to 1).

## Tech Stack
* **Language:** Python
* **Frontend UI:** Streamlit
* **NLP Engine:** TextBlob
